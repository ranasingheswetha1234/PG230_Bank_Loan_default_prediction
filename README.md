# Smart Lending – Loan Default Prediction

## Project Overview
Smart Lending is a machine learning group project that predicts whether a loan applicant is likely to repay a loan or default.

The project uses applicant information, loan details, and credit-related data to explore factors associated with loan repayment.

## Dataset
- Dataset: Loan Data
- Records: 45,000
- Features: 14
- Target variable: `loan_status`
  - `0` – Default
  - `1` – Not Default

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## Project Workflow
The project includes:
- Handling missing values and outliers
- Encoding categorical variables
- Feature scaling
- Feature engineering
- Feature selection
- Final machine learning pipeline
